# CoreFit Supply

CoreFit Supply is an online fitness equipment store created as a student project. The website provides simple and affordable fitness equipment for home workouts.

## Website Features

### Home Page
- Displays the CoreFit Supply brand and website introduction.
- Includes featured fitness products.
- Provides links to view product details.

### Shop Page
- Displays at least ten fitness products.
- Uses JavaScript to organize and display product information.
- Includes product names, descriptions, prices, images, and available stock.
- Allows customers to add products to the shopping cart.

### Product Details Page
- Displays information about individual fitness products.
- Shows the product name, description, price, and available stock.
- Allows available products to be added to the shopping cart.

### Shopping Cart
- Allows products to be added and removed.
- Displays product names, prices, and quantities.
- Allows customers to change product quantities.
- Displays the current total cost.
- Includes an option to clear the entire cart.
- Includes a button that connects to the Checkout page.
- Uses local storage so cart contents remain after refreshing the browser.

### Inventory System
- Reduces available stock when a product is added to the cart.
- Increases available stock when a product is removed.
- Prevents customers from adding products that are out of stock.
- Displays an "Out of Stock" message when inventory reaches zero.

### Checkout Page
- Displays the customer's cart information and order total.
- Includes a purchase form.
- Includes a shipping information form.
- Validates required form fields using JavaScript.
- Supports coupon code validation and discounts.
- Displays an order confirmation message after an order is placed.

### Contact Page
- Includes a contact form.
- Collects a customer's full name, email address, subject, and message.
- Validates required form fields.

### Network Connection Test
- Displays the local host name.
- Displays the current communication port.
- Displays the current transmission protocol.
- Displays the last time the page was launched.
- Allows the website's local network connection to be tested.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
